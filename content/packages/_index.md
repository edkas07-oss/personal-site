Koleksi biner rilis resmi (*standalone binaries*) untuk kakas operator infrastruktur dan platform engineering. Seluruh biner dikompilasi secara statis (`CGO_ENABLED=0`) dengan dependensi runtime nol (*zero external dependencies*), siap dijalankan secara portabel pada lingkungan Linux dan Windows Server.
